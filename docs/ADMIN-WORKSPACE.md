# Admin workspace update

Top-ups are isolated into UAH, Brainrots and Stars tabs. Brainrots retains a separate catalog-settings subview. Card and reviewer drafts prevent background repaint even after focus leaves the input. Existing catalog-save queuing and server authorization remain in place.

Partner deletion now removes the active partner, releases referred users from the deleted code and archives the complete ledger, pending balance and paid total. Archives are visible to the owner only. Deleted codes stay reserved; an archived partner cannot claim or accrue new commission. Repeated action receipts cannot apply deletion twice.

Owner-only live-feed clearing removes shared recent drops and the daily top. It preserves player inventories, balances, personal bests and activity histories. The feed revision prevents a delayed older response from repainting cleared entries. New game drops immediately start a fresh feed.

Internal appointment scheduling moves to Saturdays, 12:00–20:00 Europe/Kyiv, in 5-minute windows. New form fields align nickname, window, ordinary target and quantity. The internal preview supports up to four ordinary Garamas or canonical Cannelloni dragons per group and calculates remaining value. Booking and completion never consume or issue items, credit change, or transfer external prizes. Existing records keep their original date and can be cancelled. External gambling-prize redemption remains disabled.

The main font is locally embedded Montserrat Bold (700), with Cyrillic and Ukrainian support. Header settings uses the existing preferences dialog. The mint support button uses dark surfaces and lime accents; the back-to-cases button is removed. Fuse, Mines, case controls and admin forms use bounded responsive grids.
