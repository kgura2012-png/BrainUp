# Fonts

An earlier UI used **Unbounded**, weights 200–900, including Cyrillic. Source:
https://github.com/google/fonts/tree/main/ofl/unbounded

`unbounded-variable.ttf` is the original variable font. `unbounded-variable.woff`
is the same font compressed with fontTools for local embedding. License:
`UNBOUNDED-OFL.txt` (SIL Open Font License 1.1).

Previously embedded Montserrat and Russo One assets are retained for the existing
source components and version history.


## Earlier UI — Tektur

Tektur is bundled locally with Cyrillic and Latin support. The WOFF contains
the original variable font (width 75–100, weight 400–900), converted losslessly
from the official TTF using fontTools. License: `fonts/tektur/OFL.txt`.

Source: https://github.com/google/fonts/tree/main/ofl/tektur
Original project: https://github.com/hyvyys/Tektur

## Current UI — Montserrat Bold

Locally bundled Montserrat Bold (700), including Cyrillic and Ukrainian. The official variable font was instantiated at weight 700 with fontTools and saved as WOFF. License: `fonts/montserrat/OFL.txt`.
Source: https://github.com/google/fonts/tree/main/ofl/montserrat
