# BrainUp

Исходники актуальной опубликованной версии 172.

## Локальный запуск

Требуется Node.js 24 или новее.

```sh
npm ci
npm run dev
```

## Проверки и самостоятельная сборка

```sh
npm test
npm run build:cloudflare
```

Проект содержит сервер Cloudflare Worker, базу D1 и хранилище загрузок. GitHub хранит исходники; GitHub Pages не запускает эту серверную часть.

Подготовка внешнего хостинга, перенос действующей базы и настройка секретов описаны в [CLOUDFLARE-RU.md](CLOUDFLARE-RU.md).
Секреты окружения задаются на хостинге. Рабочая база, секреты и служебная конфигурация текущего сайта не включены в этот экспорт. Публикация кода сама по себе не переносит аккаунты, балансы или Telegram webhook.
