# BrainUp — обновлённая версия

## Что изменено

### Обновление 4.1

- Карточки лайв-дропа и топ-дропа дня используют одинаковую вёрстку, фиксированную высоту и обрезку длинного текста. На компьютере лента прокручивается вертикально, на телефоне — горизонтально.
- Лайв-дроп берётся из серверных результатов всех игроков, включая выигрыши монетами. Повторное получение ответа не добавляет повторный дроп. Дневной рекорд сохраняется отдельно от последних событий и сбрасывается по времени Киева.
- Окно кейса оформлено по предоставленному примеру: центрированная картинка, ограниченная по ширине рулетка, переключатели ×1/×3/×5, скорость и сетка призов. Исправлены растягивание сетки и центрирование результата при изменении ширины окна.
- Добавлены короткие звуки проигрыша в дайсах и минах; учитываются общая громкость и отключение звука.
- Кнопка меню придвинута к левому краю основной части. Раздел «Квесты» убран из меню и маршрутизации.
- Картинки бонусов заменены: бонус-код — Dragon Canelonni; подписка — Garama and Madundung; реферальный кейс — Strawberry Elephant. Это оформление карточек, а не обещание выпадения конкретного предмета.
- Разведены текст, таймер и кнопка cashback, чтобы они не накладывались друг на друга.

- Адаптация для телефона, крупные элементы управления, увеличенное окно кейса.
- В режиме стримера расширен список слов на русском, украинском и английском: апгрейды, кейсы, дайсы, кости, ракетка, мины и другие игровые термины. Размытие не гарантирует отсутствие блокировок со стороны площадок.
- Магазин считает цену как стоимость предмета × 1,05. Добавлен текст: «Цена выше стоимости брейнрота на 5%. Купленное нельзя вывести, только отыграть или продать». Продажа возвращает стоимость предмета, без возврата наценки.
- Дорогие предметы в кейсах выпадают реже: вес предмета равен `цена ^ −1,8`, нормализованный по содержимому кейса. Вероятности показаны рядом с призами и соответствуют серверному выбору.
- Ракетка остаётся случайной, с прежним техническим пределом ×1000, но вероятность больших множителей уменьшена. Приблизительно: достижение ×2 — 31%, ×10 — 2,36%, ×50 — 0,18%. Результат и расчёт выигрыша определяет сервер.
- На каждое воскресенье создаётся очередь без лимита мест. Заявка получает дату и постоянный номер. Обработка происходит по очереди, по воскресеньям, по времени Киева. Отклонение возвращает предметы или партнёрские средства.
- Реферальная привязка одна на серверный аккаунт и сохраняется при смене ника и отключении партнёра.
- Создание партнёрского промокода резервирует с основного баланса полную стоимость всех активаций. При удалении возвращается только неиспользованный остаток.

## Локальный запуск

1. Распакуйте архив в отдельную папку.
2. Запустите `START-BRAINUP.cmd`.
3. Откройте `http://127.0.0.1:4173` в браузере.

Нужен Node.js 24 или новее. На этом компьютере запуск использует уже имеющийся runtime Codex. Установка библиотек не требуется.

Локальный сервер использует тестовый аккаунт Owner. Это проверочный режим для одного компьютера; не открывайте его в интернет. База SQLite автоматически создаётся в `.sites-runtime/preview.sqlite`. Для хостинга используется Cloudflare D1, а пользователи определяются по проверенной платформой идентичности.

При открытии `site.html` двойным щелчком работает автономный браузерный макет. Для серверных правил, базы данных и общей очереди запускайте сервер.

Начальный серверный баланс — 0. Владельцу доступна админка через меню или `#admin`: для локальной проверки можно начислить монеты тестовому аккаунту, купить предмет и проверить интерфейс.

## Размещение и перенос

Рабочая площадка: https://brainup-mobile-nov26.regalpeach22.chatgpt.site/

Подготовлен самостоятельный вариант для Cloudflare Workers, D1 и Static Assets. Конфигурация — `wrangler.jsonc`, сборка — `npm run build:cloudflare`, проверка без публикации — `npm run cf:check`. Инструкция по авторизации, полной резервной копии, переносу данных, секретам и переключению Telegram — [CLOUDFLARE-RU.md](CLOUDFLARE-RU.md).

Самостоятельная сборка принимает только проверенные сервером данные Telegram Mini App и игнорирует заголовки идентификации Sites. Идентификаторы `tg:...` и права владельца сохраняются с production-базой. Текущую площадку нельзя отключать до проверки переноса. Локальная тестовая SQLite не заменяет рабочую базу.

Баланс и инвентарь проверяются сервером. Заявки на пополнение предметами работают как бесплатная внутренняя симуляция. Пополнение через Telegram Stars начисляет 1,35 BU за звезду после подтверждения Telegram. Старые счета поддержки обрабатываются по исходным условиям.

## Проверки

`node --test tests/economy.test.mjs tests/feed.test.mjs` — серверные сценарии, SQLite, одновременные запросы, повторная обработка и общая лента дропов.

`node scripts/build-brainup.mjs` — сборка Worker и проверка синтаксиса встроенного JavaScript.

В проверке 100 000 раундов ракетки: ×2 достигнут в 30 707 случаях, ×10 — в 2 297. Это статистическая проверка распределения, не обещание результатов отдельных раундов.
